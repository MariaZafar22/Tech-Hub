## ⚡ Commands
### 1. chmod — Change Mode
Changes file permissions for read, write, or execute access.
### 2. ps — Process Status
Shows all running processes with memory and CPU usage.
### 3. kill — Terminate Process
Kills a running process using its unique PID.
### 4. sudo apt update
Refreshes available software updates on the system.
