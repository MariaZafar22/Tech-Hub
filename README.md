📋 Overview
This assignment covers 4 essential Linux commands with explanations, syntax, and outputs.
⚡ Commands
1. chmod (Change Mode)
Used to change the permissions of a file — making it readable, writable, or executable for a user or owner.
chmod [options] permission filename
2. ps (Process Status)
Displays currently running processes along with their processing speed and memory usage.
ps [options]
3. kill ID
Every process has a unique ID (PID). This command terminates a specific running program using its PID.
kill [option] PID
4. sudo apt update
sudo = Super User Do | apt = Advanced Package Tool
Checks what latest updates are available for software installed on the system.
sudo apt update
